# `lua/config/options.lua`

## 作用

这个文件只处理基础编辑选项，目前主要集中在缩进策略。

## 为什么这样写

- 这里只放最稳定、最通用的编辑器基础行为。
- 没有加入太多 UI 或文件类型细节，说明你在刻意把“编辑基础”和“插件层行为”分开。

## 当前配置的含义

- `expandtab = true`
- `shiftwidth = 2`
- `tabstop = 2`
- `softtabstop = 2`

这四个组合起来，表示你希望：

- 输入 Tab 时实际写入空格
- 缩进宽度固定为 2
- 显示和编辑时都按 2 空格理解 Tab

## 为什么这样配

- 对前端和 Lua 配置来说，2 空格是低摩擦、兼容度高的选择。
- 把显示宽度、编辑宽度、缩进宽度统一，可以减少“看起来对齐但实际不一致”的情况。

## `smarttab` / `smartindent` / `autoindent`

这三项一起开，说明你的目标不是“完全手工控制缩进”，而是让编辑器在常见场景下尽量顺着前一行和语法自动补缩进。

原因：

- 这是典型的“降低重复输入”策略。
- 它不会像更激进的格式化器那样强行重排整段文本，但能保持基本编辑顺手。
