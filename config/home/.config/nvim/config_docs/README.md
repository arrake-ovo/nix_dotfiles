# 配置文档索引

这套文档只解释当前仓库里的自定义配置，不解释 LazyVim 或插件上游的全部功能。

命名规则：

- `config_docs/config/*.md` 对应 `lua/config/*.lua`
- `config_docs/plugins/*.md` 对应 `lua/plugins/*.lua`

阅读顺序建议：

1. 先读 `preferences.md`
2. 再读 `config/colemak.md`
3. 然后读 `config/keymaps.md`
4. 接着读 `plugins/navigation.md`、`plugins/flash.md`、`plugins/lsp.md`
5. 最后再看 `plugins/dap.md`、`plugins/git.md`、`plugins/ui.md`
