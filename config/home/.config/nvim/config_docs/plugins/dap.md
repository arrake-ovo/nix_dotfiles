# `lua/plugins/dap.lua`

## 作用

这个文件负责调试相关键位，覆盖 `nvim-dap` 和 `nvim-dap-ui` 的默认行为。

## 为什么这样写

- 你对调试界面的主要诉求不是“扩展更多功能”，而是先让基本方向和入口符合自己的键位系统。
- 所以这里重点不是新增命令，而是替换默认键位、减少冲突。

## `nvim-dap` 部分

### 取消 `<leader>dj` / `<leader>dk`

原因：

- 这两组默认键依赖传统 `j/k` 方向思维。
- 你的整体方向语义已经迁移到 `u/e/n/i`，继续保留 `j/k` 会破坏一致性。

### 改成 `<leader>de` / `<leader>du`

- `de` = down
- `du` = up

这说明你希望调试栈导航直接贴合 Colemak 方向。

## `nvim-dap-ui` 部分

### `expand/open/edit`

- `i` 用来展开或打开
- `I` 用来 edit

原因：

- 你已经把 `i` 作为“向内/确认/进入”的一类动作使用在多个界面里。
- 所以在 DAP UI 里继续用 `i` 表示展开，是在延续同一套界面语义。

### `dE` / `dU`

- `dE` 保留 Eval
- `dU` 用来 toggle UI

原因：

- 小写 `de` / `du` 已经给了上下移动。
- 大写再承接另一层调试动作，既不抢位，也保持分组整齐。
