# `lua/plugins/format.lua`

## 作用

这个文件目前定制的是 `trouble.nvim`，重点在“问题列表如何展示、如何移动”。

## 为什么文件名叫 `format`

从内容看，这个文件更像“诊断/问题列表格式和交互”。

当前命名可能来自你对“格式化与诊断展示”这一层的整体归类，而不是严格只放 formatter。

## 具体改了什么

### `lsp` 模式窗口放到右侧

原因：

- 右侧适合做参考面板，不会像底部那样压缩横向内容。
- 对代码阅读来说，把问题列表放右边，主编辑区更稳定。

### `trouble` 内部键位改成 Colemak 方向

- `u` 上一个
- `e` 下一个
- `n` 关闭
- `i` 跳转
- `I` inspect

原因：

- `trouble` 本质上也是列表界面。
- 既然 `snacks`、`mini.files`、部分 buffer 已经统一了方向语义，这里继续统一是必要的。
